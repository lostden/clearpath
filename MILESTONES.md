## Checkpoint acceptance

For each increment, record the code state, exact commands run and outcomes, material limitations, remaining phone tests, and a coherent commit when local Git permits. A passing typecheck does not prove live alert availability or physical map rendering. The presence of an integration file is not evidence of successful integration.

For milestone 5, the student supplies the design note and implementation described in STUDENT_CONTRIBUTIONS.md. Review that work and its meaningful tests before enabling it in the live presentation. Preserve authorship in commits and AI_USAGE.md.
