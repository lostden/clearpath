## Exact off-camera preparation

1. Open HOME. Preserve existing preparation and selected-point data; do not clear Expo Go/app storage. Resolve any loading/error screen before recording.
2. Scroll to TRAINING DEMO → **Explore simulated demo**. This sets the scenario to **North Texas flood**. If already in demo, tap **NORTH TEXAS FLOOD** (`Simulate North Texas flood` is its accessibility label).
3. Confirm **Frisco · North Texas training point**, **SIMULATED DEMO**, a simulated flash-flood headline and two fictional warnings. Fixture point: **33.155424, -96.8225927**. The fixed July 4, 2025 time and all text/areas are invented; no historical incident is being reproduced. Do not manually set the phone date.
4. Tap **Read simulated warning**. Verify **SIMULATED INSTRUCTIONS**, **Read Flooding guide** and **Why this warning is shown here**. Expand the explanation. Classifications appear farther down under **ISSUANCE / TIMES**. Use short slow scrolls; keep the source context visible.
5. Tap **Read Flooding guide**. It closes the warning and opens PREPARE → FIELD GUIDES with **Flooding** expanded. Scroll to **Reviewed 2026-10-09** and **Open National Weather Service — Flood safety source**. Leave the website closed. The displayed review date is a bundled-content date, not a new incident review.
6. Tap **MAP**. Keep **Warning areas** ON. In this Frisco demo, river/earthquake/wildfire controls and live Texas/U.S. coverage are not available; do not hunt for them. Hold both areas. Use **Recenter** off camera if the map was moved, then rehearse a small pan and pinch. Map tiles need internet even though the fixture polygons are local.
7. Tap **PREPARE → KIT**. Note privately whether **Drinking water** was already checked. Set it unchecked for the shot only if this will not lose someone's needed preparation record; otherwise record an already checked item honestly and omit the staged tap. Wait for **LOCAL COPY / SAVED ON THIS PHONE**.
8. **FAMILY PLAN**: save any original Meeting place privately, outside footage. Temporarily enter **Demo meeting point** in **Meeting place** (accessibility label `Family meeting place`). This field saves automatically; there is no Save plan button. Dismiss the keyboard off camera and wait for saved status. Leave the real out-of-area contact outside the frame.
9. **CONTACTS → Add emergency contact**: enter **Demo Contact** and **202-555-0147**, then **Save contact**. It is fictional; never tap Call or 911. Frame only that card. If real contacts cannot be excluded safely, film the section heading/Add emergency contact control instead; do not erase a real contact list for a shot.
10. **LOCAL LINKS**: prepare a readable view of **City of Frisco emergency preparedness** and **NWS Fort Worth/Dallas**. Links checked 2026-10-13 is the app's existing reference-review date. Do not open websites in the main take.
11. Return **HOME**, close any warning with **Close warning**, scroll to the warning summary and retain the North Texas scenario. This is the initial state for A01. Switch Focus on and make the ten-second capture test in file 05.

Prepare writes are real local writes, not a disposable demo profile. Preserve people's data, wait for save feedback, and restore temporary values after filming. If **SESSION ONLY / CHANGES NOT SAVED** appears, stop that shot; do not narrate a successful save.

## Reset between takes without erasing data

- Warning: **Close warning → HOME → Read simulated warning**. Newly opened explanation starts collapsed; confirm visually before a take.
- Guide: return HOME and open the warning, then **Read Flooding guide** again. The new navigation request reopens the same guide without discarding drafts.
- Map: use the actual **Recenter** control, confirm both fixture areas and Warning areas ON. Do not promise that changing the scenario alone resets a panned viewport.
- Scenario: **HOME → Return to live mode → Explore simulated demo** reselects North Texas. Exit via **Exit demo** in the fixed strip if that is the visible control. Keep the restored private live point off camera. A restart opens live mode; re-enter the demo deliberately.
- Preparation: toggle only the test item back to its original state, restore the original Meeting place privately, and remove only **Demo Contact** using **Remove Demo Contact → Remove**. Wait for saved feedback. Do not reset all app data.
