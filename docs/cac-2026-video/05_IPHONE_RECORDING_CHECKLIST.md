## Before pressing Record

- [ ] Keep Mac awake, Metro reachable and Wi-Fi on. Charge the phone; enough free storage for several takes. Keep a charger nearby without framing private computer information.
- [ ] End iPhone Mirroring; screen recording and mirroring cannot run together. Set a Focus that silences unrelated notifications, and check its allowed contacts/apps before the trial.
- [ ] Close unrelated apps; do not show lock screen, email, photo library, home address, actual contacts or permission dialogs. Use file 02’s privacy-preserving preparation; do not clear real data.
- [ ] Lock portrait orientation for app clips; moderate brightness and comfortable normal text size. Keep accessibility settings needed by the operator; inspect any layout difference.
- [ ] On a Face ID iPhone, swipe down from the top-right → Screen Recording. On a Home-button iPhone, swipe up from the bottom to open Control Center instead. Add that control first if missing. Hold it and leave Microphone OFF for silent screen footage. Tap to start, wait the three-second countdown, return to ClearPath. Stop via the red recording indicator and review in Photos. [Apple’s instructions](https://support.apple.com/guide/iphone/take-a-screen-recording-iph52f6e1987/ios).
